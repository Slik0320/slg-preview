Sam's Liquor Group

Everything built so far, in one place.

Each tab above opens a working part of the build. It all runs on demo data held in this browser, so you can place orders, claim them and click anything without touching the live system. Nothing is saved anywhere else.

What to try

  • Wholesale Shop — search a product name or an IQ stock code (CA456, BU035). Products with more than one pack size let you switch between single, case and bulk, each at its own price.
  • Build an order and send it — you'll get a reference back.
  • Trade Desk — sign in as any of the demo staff. The order you just placed is at the top of the queue, unclaimed.
  • Claim it. Sign in as someone from a different store and see that they can't claim it twice.
  • Fleet Care — sign in with a staff number and PIN on the keypad. Admin 100 / 9999, fleet controller 301 / 5005, workshop 302 / 6006 (five vehicles only), driver 401 / 1001. Try each — what you see changes with who you are.
  • Reset demo in the amber bar puts everything back to the start.

What is not real yet

  • The catalogue is an 84-product sample of the real 766. Prices and codes are real.
  • Staff sign-in has no password in this build — it is a role switcher.
  • Quoting, picking and the price-list admin are not built yet.
  • The Event Bars enquiry form needs its EmailJS template before it will send.
  • Fleet Care is the design prototype on seeded data — all 18 screens are shown so the team can decide which to keep for V1. Nothing in it is saved anywhere.
